# 4-Bit Decimal to Binary Encoder (Logisim Project)

This project is a digital logic circuit implemented in **Logisim Evolution** that encodes a single active decimal input (from 0 to 15) into its **4-bit binary equivalent**. The circuit is constructed using basic logic gates such as OR, AND, and NOT.

## 🧠 How It Works

- Accepts one active input among 16 input lines (0–15)
- Outputs a 4-bit binary number corresponding to the active input's index
- Built using basic logic gates for educational and simulation purposes

## 📂 File Included

- `dectobinary.circ` — Logisim Evolution circuit file for the encoder

## 🛠 Tools Used

- [Logisim Evolution](https://github.com/reds-heig/logisim-evolution): A digital logic simulator

## 💡 Features

- Real-time encoding of decimal input to binary output
- Visual and editable circuit layout
- Ideal for learning digital logic, encoders, and binary representation

## 🚀 How to Run

1. Download and install **Logisim Evolution**
2. Open the file `dectobinary.circ` using Logisim
3. Simulate the circuit by activating any one of the input lines (0–15)
4. Observe the 4-bit binary output
